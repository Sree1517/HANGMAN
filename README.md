# Web Hangman Game
A simple web-based Hangman game built using Python and Flask.  
Users can guess letters to complete a 5-letter random word.  
## Features
- Random 5-letter word generation
- Shows word blanks and guessed letters
- Keeps track of remaining attempts
- Win/Lose messages
- Prevents repeated guesses
## Requirements
- Python 3.x
- Flask
- NLTK

Install dependencies using:

```bash
pip install -r requirements.txt
